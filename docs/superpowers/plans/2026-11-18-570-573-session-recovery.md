# Session recovery implementation plan

Build1 implements the [#570/#573 design](../specs/2026-11-18-570-573-session-recovery-design.md) inline with executing-plans, starting from this approved head. Keep both documents in the fix PR. Work in the current V2 session paths, SwiftData and private DeviceSync; no new cloud record or schema migration is required.

- App: `Foqos/Utils/{StrategyManager,OrphanedSessionCleanup,PreActivationReminderScheduler}.swift`, `Foqos/Models/{BlockedProfileSessions,BlockedProfiles}.swift`, `Foqos/CloudKit/{SessionSyncService,SessionStopOutbox,ProfileSessionRecord}.swift` and `Foqos/CloudKit/SyncEngine/SyncApplyService.swift`. Keep reconciliation inside the existing manager entry points used by launch, Home, remote apply and outbox drain. Keep startSessionFromBackground and stopSessionFromBackground signatures stable for build2’s intent consumers. Build2 exclusively owns FoqosApp.swift, AppModelStore.swift, app startup, Intents sources and TimersUtil.swift.
- Tests under `FoqosTests/`: StrategyManagerRemoteSessionTests, SessionTimerCASTests, SharedDataSessionIdentityTests, SharedDataLockTests, SessionStopOutboxTests, SyncApplyServiceTests, ScheduleTimerActivityTests, OrphanedSessionCleanupTests, RestrictionApplyCurrentStateTests, RestrictionGrantsOpenTests, RestrictionGrantsCloseTests, DeleteProfileCleanupTests, LogPrivacyTests, and new SessionRecoveryTests; their session-specific recording doubles in Helpers/ and Mocks/. Own `docs/session-lifecycle.md` and a separate SessionRecoveryUITests.swift under FoqosUITests if needed.
- The sole shared write is `FamilyFoqos.xcodeproj/project.pbxproj` for required version increments. Use synchronized source groups. Ask the orchestrator for the version slot once ready; first finisher bumps both versions and merges, second merges current main with a signed merge and bumps from that base. Never overwrite the first bump. Build2 can proceed independently on #572.
