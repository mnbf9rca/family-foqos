- Multi-parent support - A second parent can now join and manage the family. Just send them the share invite and they'll automatically get parent access.
- Bug fix - Kids can now stop their own focus sessions without needing a lock code. Lock codes are still required to edit or delete locked profiles.
- Housekeeping - Removed the NFC tag purchase link from Settings.
- Stability - Fixed a crash that could happen when profiles were synced across devices.
- Rollout note - During this rollout, emergency unblock limits are per-device until all your devices update. Usage from devices on the old app version isn't shown on updated devices, and each device's allowance starts fresh when it updates.
- Sync compatibility - Devices still on the old app version won't be affected when you totally delete synced data and can't interoperate with the new sync. Update Family Foqos on every device first.
- Under the hood changes to prepare for more granular profile settings.
- Siri and Shortcuts - Start a named profile, stop an eligible profile, or ask “Am I blocking right now in Family Foqos”. Status works while locked and names the active profile, break or one-more-minute grant, and available timer or schedule timing.
- Profile permission - Upgraded NFC Tags and QR Codes profiles still start from their tags and codes, but no longer start from other links or Shortcuts. To restore those starts, turn them on. If the profile stops with the same tag or code, also add another stop.
- Timer - You can choose a different duration for an interactive start. Tag, link, Shortcut and scheduled starts use the saved duration.
- Duration - This start uses the profile’s saved timer. Remove Duration from the Shortcut or edit the profile’s timer.
- Tags and links - Scanning an NFC tag or QR code can stop a profile only if its stop settings allow it. Opening a link without scanning cannot stop a profile.
- Device unlock - Start and stop require this device's authentication by default. Settings → Siri & Shortcuts → Require Device Unlock controls both; turn it off for eligible unattended actions. Profile start and stop restrictions still apply, and read-only status is unaffected.
- Family names - Family Controls now uses live iCloud share names instead of saved names. Participant names are no longer stored or included in diagnostic roster exports. Name availability on iOS 27 is awaiting device verification: if iCloud supplies no name, even a previously named member now appears as “Child” or “Parent”.
